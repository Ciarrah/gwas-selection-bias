Scenario

Figure 2(b). Genotype G affects a secondary phenotype Y and disease D, and Y also affects D. Cases are over-sampled: the study has equal numbers of cases and controls, although only 5% of the population has the disease. Analysing Y in this sample conditions on D, which distorts the SNP-Y associations:

  • SNPs affecting only disease (D_snps) become associated with Y;
  • SNPs affecting Y (Y_snps) are biased.

Two secondary phenotypes (Y1, Y2) have the same SNP effects on the standardised scale. Only Y1 affects disease.

naive <- run_gwas(p$Y1, d$G)

             digits = 3, row.names = FALSE)

naive (Y1) D_snps NaN 0.032 0.550 0.450
naive (Y1) null NaN 0.013 0.938 0.062

Disease-only SNPs show spurious associations with Y1 well above the nominal 5%, and the Y-acting SNPs are biased.

2. Diagnostics

There is no diagnostic specific to this design: the sampling scheme is known, so bias should be assumed whenever a secondary phenotype is analysed in a case-control sample. Variants known to affect only the disease can serve as negative control variants (see module c).

3. Corrections

All three corrections use the known population prevalence of the disease (K = 0.05).

Inverse probability weighting

Each case and control is weighted by its population share divided by its sample share.

w    <- case_control_weights(p$D, d$K)
ipw1 <- ipw_gwas(p$Y1, d$G, w)

knitr::kable(data.frame(group = c("cases", "controls"),
                        weight = round(c(w[p$D == 1][1], w[p$D == 0][1]), 3)),
             row.names = FALSE)

Scaled marginal model

When several secondary phenotypes share SNP effects, the scaled marginal model estimates one common effect across them by weighted GEE, gaining precision over analysing Y1 alone.

smm <- smm_gwas(p[, c("Y1", "Y2")], d$G, w)
knitr::kable(rbind(
  compare_by_group(naive, d$truth, d$groups, "naive (Y1)"),
  compare_by_group(ipw1,  d$truth, d$groups, "IPW (Y1)"),
  compare_by_group(smm,   d$truth, d$groups, "SMM (Y1 + Y2)")
)[, cols], digits = 3, row.names = FALSE)

4. Summary

grp <- rep(names(d$groups), lengths(d$groups))[order(unlist(d$groups))]

est <- function(res, label) {
  data.frame(analysis = label, snp_group = grp, truth = d$truth,
             beta = res$beta)
}

plot_df <- rbind(est(naive, "naive (Y1)"), est(ipw1, "IPW (Y1)"),
                 est(smm, "SMM (Y1 + Y2)"))
plot_df$analysis <- factor(plot_df$analysis, levels = unique(plot_df$analysis))

ggplot(plot_df, aes(truth, beta, colour = snp_group)) +
  geom_abline(slope = 1, intercept = 0, linetype = "dashed", colour = "grey50") +
  geom_point(alpha = 0.7) +
  facet_wrap(~ analysis, nrow = 1) +
  labs(x = "True SNP effect", y = "Estimated SNP effect",
       colour = "SNP group") +
  theme_bw()

Points on the dashed line are unbiased. In the naive analysis, disease-only SNPs (true effect 0) spread away from zero. Weighting by the known sampling fractions brings them back, and the scaled marginal model does so with the smallest errors by pooling the two secondary phenotypes.
